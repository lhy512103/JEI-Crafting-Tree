# Contributing

## English

Thanks for helping improve JEI Crafting Tree.

### Development Setup

1. Install Java 21.
2. Clone the repository.
3. Import the Gradle project into IntelliJ IDEA or another Java IDE.
4. Run `.\gradlew.bat compileJava` before submitting changes.

### Pull Requests

- Keep changes focused on one feature or bug fix.
- Do not commit `build/`, `run/`, `.gradle/`, IDE metadata, or generated jars.
- Update translations when adding user-facing text.
- Update `README.md` or `CHANGELOG.md` when behavior changes in a way users should know about.

### Issue Reports

Please include:

- Minecraft, NeoForge, JEI, and JEI Crafting Tree versions.
- Whether AE2 Utility or another backend provider is installed.
- A short description of what you expected and what happened.
- Relevant logs or crash reports when available.

## 中文

感谢你帮助改进 JEI Crafting Tree。

### 开发环境

1. 安装 Java 21。
2. 克隆本仓库。
3. 将 Gradle 项目导入 IntelliJ IDEA 或其他 Java IDE。
4. 提交修改前运行 `.\gradlew.bat compileJava`。

### Pull Request

- 每次修改尽量聚焦在一个功能或一个 bug 修复上。
- 不要提交 `build/`、`run/`、`.gradle/`、IDE 元数据或生成的 jar 文件。
- 添加面向用户的文本时，请同步更新翻译。
- 如果行为变化会影响用户理解或使用，请更新 `README.md` 或 `CHANGELOG.md`。

### 问题反馈

请尽量提供：

- Minecraft、NeoForge、JEI 和 JEI Crafting Tree 的版本。
- 是否安装了 AE2 Utility 或其他后端提供方。
- 简短说明你期望发生什么，以及实际发生了什么。
- 如有相关日志或崩溃报告，也请一并提供。
